A few lines using a built-in module

Save this as server.cjs next to index.html, then run the command below in that folder. It uses Node.js core modules, with no packages to install.

server.cjs
const http = require("node:http");
const { readFileSync } = require("node:fs");
const page = readFileSync("index.html");

http.createServer((request, response) => {
  if (request.url !== "/" && request.url !== "/index.html") {
    response.writeHead(404).end();
    return;
  }
  response.writeHead(200, { "Content-Type": "text/html; charset=utf-8" });
  response.end(page);
}).listen(8000, "127.0.0.1");
Terminal
node server.cjs

07 / FREQUENTLY ALARMED QUESTIONS

A few things
to clear up

Is this actually a vulnerability?+

No. Browser2JS describes an intended feature as an alarming discovery. The severity rating and advisory identifier are fictional.

Is code from a remote server really executed?+

Yes. Browsers normally process JavaScript within their security boundaries. Real vulnerabilities, such as HTTP2Shell in affected browser components, are a separate issue and can undermine those protections. Keep your browser up to date.

Does this escape the browser sandbox?+

No. This demo shows a simple alert inside the browser, not a sandbox escape, privilege escalation, or arbitrary native code execution.

Are the vendor quotes real?+

No. The exchange is made up for this joke. No vendor refusal or disclosure process is being reported.
